# ArcheAge PlayerBots 3-0

Frozen ArcheAge 3.0.4.2 r336598 variant.

**Role:** Compatibility snapshot. **Status:** source preview. Regression and compatibility work only; 1.2 host patches and newer Core features are not interchangeable.

[Master workspace](https://github.com/NulightJens/ArcheAge-PlayerBots-Master) · [Current status and next work](https://github.com/NulightJens/ArcheAge-PlayerBots-Master/blob/main/docs/STATUS.md)

From the master root, run `python playerbots.py fetch 3-0`, then `cd variants/3-0`. The commands below also support a standalone clone.

## Get the source

```powershell
git clone --recurse-submodules https://github.com/NulightJens/ArcheAge-PlayerBots-3-0.git
cd ArcheAge-PlayerBots-3-0
```

This repository requires GitHub access from its owner.

## Setup

Requires Git, Python 3.11+, .NET 10 SDK and your own matching client/data. The server owner installs this module. From this repository directory:

```powershell
git clone https://github.com/NL0bP/AAEmu ../AAEmu-3-0
git -C ../AAEmu-3-0 checkout 8c1c943bb2309eefffb9da2aa99a408d0acbb095
python install.py --host ../AAEmu-3-0 --check
python install.py --host ../AAEmu-3-0
```

Use a new host directory for each installation. The installer verifies the host revision and applies source changes; it does not configure a database or start a server. [Complete host setup and build instructions](https://github.com/NulightJens/ArcheAge-PlayerBots-Master/blob/main/docs/SETUP.md).

## Commands

After configuring the matching 3.0 host and client, use `/bot` or `/bothelp` in game. Use the help provided by this variant; Core and Experiment commands are not interchangeable. Keep this server and its database separate from 1.2 installations.
