# ArcheAge PlayerBots 10x

Control bots through bounded native operations on the matching ArcheAge 10.x host.

**Role:** Native prototype. **Status:** source preview. Bounded native-zone operations, not autonomous world population.

[Master workspace](https://github.com/NulightJens/ArcheAge-PlayerBots-Master) · [Current status and next work](https://github.com/NulightJens/ArcheAge-PlayerBots-Master/blob/main/docs/STATUS.md)

From the master root, run `python playerbots.py fetch 10x`, then `cd variants/10x`. The commands below also support a standalone clone.

## Get the source

```powershell
git clone --recurse-submodules https://github.com/NulightJens/ArcheAge-PlayerBots-10x.git
cd ArcheAge-PlayerBots-10x
```

You need access to this private repository before cloning it.

## Setup

Requires Git, Python 3.11+, .NET 10 SDK and your own matching client/data. Install this module on your server. From this repository directory:

```powershell
git clone https://github.com/AAEmu/AAEmu ../AAEmu-10x
git -C ../AAEmu-10x checkout 489e114a6ead0108bd484eac70c37a3e11fe7c51
python install.py --host ../AAEmu-10x --check
python install.py --host ../AAEmu-10x
```

Use a new host directory for each installation. The installer verifies the host revision and applies source changes; it does not configure a database or start a server. [Complete host setup and build instructions](https://github.com/NulightJens/ArcheAge-PlayerBots-Master/blob/main/docs/SETUP.md).

## Commands

Build `AAEmu.WorldServer/AAEmu.World` with `-p:PlayerBotsNativeExperiment=true`. Before starting that test host, set `AAEMU_PLAYERBOT_EXPERIMENT=1`.

```powershell
python playerbots.py --help
python playerbots.py --server http://127.0.0.1:1280 snapshot
```
Available operations include `admit`, `create`, `stop`, `logout`, `quest-step`, `fight-step`, `interact`, `doodad`, `portal-step`, `return` and `ray`. Follow the CLI help for required IDs and arguments. Each operation is explicitly requested; this is not a background autonomy loop.
